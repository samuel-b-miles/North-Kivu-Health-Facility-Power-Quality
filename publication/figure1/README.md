# Figure 1 source and reproduction

`figure1_full_frames.pdf` is the manuscript Figure 1 artwork. Rebuild it with:

```bash
python publication/figure1/build_figure1.py
```

The three source photographs in `sources/` retain their original pixels and
dimensions. Camera metadata was removed without recompressing the JPEG image
data, including GPS metadata in the middle photograph. The builder arranges
each complete frame as panels a–c, preserving the prior manuscript layout.
