# Table 2 generated from public DHIS2 panels

The submission build runs `scripts/run_health.py --from-public` then typesets
the existing Table 2 metrics, rounded to one decimal place. No values are
hard-coded in the PDF renderer. Run `python scripts/build_submission_pdf.py`.

The caption-free PNG now matches Table 1's fonts, content width, cell spacing
and rules. Body text is approximately 10 pt when inserted at 6.5 inches wide.
`python scripts/export_submission_tables.py` produces both 4500-pixel-wide
600-DPI PNGs, also generated by `scripts/build_submission_pdf.py`.
The image retains a concise statistical footnote; its caption and fuller
interpretation should be placed in manuscript text.
